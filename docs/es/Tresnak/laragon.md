## Instalación de Laragon

Las últimas versiones de Laragon solicitan una licencia; para evitarlo, debemos instalar una versión anterior a la 8.0.0.

Para ello, iremos al repositorio de Laragon en GitHub para encontrar una versión anterior:

<https://github.com/leokhoa/laragon/releases>

Dentro de Assets descargaremos el archivo laragon.exe.
