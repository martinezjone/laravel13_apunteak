# ¿Qué es Laravel y cómo funciona?

Laravel es uno de los frameworks de PHP más utilizados y mejor valorados por la comunidad de desarrolladores.

Pero ¿qué es un framework? Es un esquema de trabajo: ofrece una estructura básica para crear un proyecto y sirve como punto de partida para organizar y desarrollar software. Laravel facilita especialmente el desarrollo de aplicaciones web.

Su diseño de software se basa en el patrón MVC (Modelo-Vista-Controlador); por tanto, proporciona una base estructurada para empezar a desarrollar el código.

## MVC

![Esquema MVC (Modelo-Vista-Controlador)](../../assets/images/Zer%20da/b7657af9ea422752e0cc78138848640c.jpg)

MVC es un patrón de arquitectura de software.

Quizá, dicho así, al principio te parezca muy difícil de entender, pero en realidad no es más que una forma de estructurar el código.

Modelo (Model): Se encarga de gestionar los datos de la aplicación. Normalmente, esos datos están vinculados a una base de datos. Por ejemplo, puedes definir un modelo User para trabajar con los datos de la tabla users.

Vista (View): Como indica su nombre, se encarga de la parte visual del proyecto; es decir, en la vista se construye la interfaz que verá el usuario. Por ejemplo, una vista puede mostrar la sección del perfil de un usuario.

Controlador (Controller): Corresponde a la parte lógica de la aplicación. Los controladores conectan las vistas con los modelos. Por ejemplo, un controlador puede decidir si muestra una vista u otra según los permisos de un usuario.

![Esquema de funcionamiento de Modelo, Vista y Controlador](../../assets/images/Zer%20da/3d2c97ea28b75e9248a2c702085a6fb4.jpg)

Una de las mayores ventajas de Laravel es que cuenta con numerosas bibliotecas y módulos para ampliar sus funcionalidades.

Laravel es un framework orientado al trabajo en el lado del servidor. Sin embargo, ofrece su propio sistema de vistas, llamado Blade, con el que puedes crear tu interfaz sin ningún problema usando Laravel.

Laravel trabaja con cuatro conceptos básicos que debes aprender si quieres entender cómo funciona: rutas (rutas), modelos (modelos), vistas (vistas) y controladores (controladores).
