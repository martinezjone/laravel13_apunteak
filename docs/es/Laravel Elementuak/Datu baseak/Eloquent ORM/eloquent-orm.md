Eloquent es el ORM (Object-Relational Mapping) de Laravel; facilita el uso de operaciones SQL y mejora la seguridad de las aplicaciones.

Gracias a este ORM, podremos utilizar cada fila o registro de la base de datos como si fuera un objeto.

Para poder utilizar Eloquent, tendremos que crear modelos.

Documentación oficial: <https://laravel.com/framework/docs/13.x/eloquent-relationships>
