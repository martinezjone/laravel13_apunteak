# Proiektu bat sortu

### Froga aplikazioa

Hasteko froga aplikazio bat sortuko dugu.

### Laravel proiektu bat sortzeko

Laravel proiektu bat sortzeko hurrengo pausuak jarraitu behar ditugu:

1. MAMP hasiko dugu zerbitzaria martxan jartzeko
2. Nahi dugun kontsola hasiko dugu ere, GitBash edo nahi duguna
3. Hasiko dugu proiektu bat "froga" izenekoa. Horretarako lehenengo gauza egin behar duguna da, gure kontsolan nahi dugun karpetan kokatu.

$ cd c/xampp/htdocs/laravel\_proiektuak

composer create-project laravel/laravel froga

Lan hau egiten denbora pizkatxo bat egongo da, gauza asko bait dira sortzen ari dituenak.

4. Dena ondo egin duela konprobatuko dugu, horretarako, esandako karpetan topatuko dugu froga karpeta bat, zabaldu Visual Studion eta ikusiko duzue zelan dauden karpeta pilo barruan.

Bestetik, nabigatzaileak gure url sartzerakoan, nire kasuan: <http://localhost/2025-2026/laravel/froga/>
