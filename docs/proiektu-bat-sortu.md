# Proiektu bat sortu

### Aula aplikazioa

Aula aplikazio bat sortuko dugu Laravelekin. Ikasleak, irakasleak eta kurtsoak izango ditugu aplikazio honetan, eta 3 taula horien kudeaketa egingo dugu.

Horretarako lehenengo gauza egingo duguna gure Laravel proiektua sortzea izango da.

### Laravel proiektu bat sortzeko

Laravel proiektu bat sortzeko hurrengo pausuak jarraitu behar ditugu:

1. XAMPP edo MAMP hasiko dugu
2. Nahi dugun kontsola hasiko dugu ere, GitBash edo nahi duguna
3. Hasiko dugu proiektu bat "eskola" izenekoa. Horretarako lehenengo gauza egin behar duguna da, gure kontsolan nahi dugun karpetan kokatu.

$ cd c/xampp/htdocs/laravel\_proiektuak

composer create-project laravel/laravel eskola

Lan hau egiten denbora pizkatxo bat egongo da, gauza asko bait dira sortzen ari dituenak.

4. Dena ondo egin duela konprobatuko dugu, horretarako, esandako karpetan topatuko dugu eskola karpeta bat, zabaldu Visual Studion eta ikusiko duzue zelan dauden karpeta pilo barruan.

Bestetik, nabigatzaileak gure url sartzerakoan, nire kasuan: <http://localhost/laravel2025-2026/eskola>
