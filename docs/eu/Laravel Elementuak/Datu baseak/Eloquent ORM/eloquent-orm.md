Erlazioak

Laravelen dagoen ORM (Object-Relational Mapping) da Eloquent, eta SQL eragiketen erabilera erraztu eta aplikazioen segurtasuna hobetzen du.

ORM honi ezker, datu baseko fila, erregistro, bakoitza objetu baten moduan erabili ahal izango dugu.

Eloquent erabili ahal izateko, modeloak sortu beharko ditugu.

Dokumentazio ofiziala: <https://laravel.com/framework/docs/13.x/eloquent-relationships>
